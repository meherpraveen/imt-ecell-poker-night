Tournament format

Each round starts with 10,000 chips per player.

    Qualifiers

    Six waves of up to 36 players. The chip leader at each table advances.

    Semifinals

    The table winners play for one of six seats in the final.

  3. Round 360 min

    Final table

    The player with the most chips wins a poker set and a speaker.
